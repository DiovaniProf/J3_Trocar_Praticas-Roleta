IMPORTANTE — TELA CHEIA
Por razões de segurança, GitHub Pages e navegadores como Chrome, Edge e Firefox
não permitem garantir tela cheia real (ocultando barra de endereços) no carregamento
sem uma ação do visitante. A interface já ocupa toda a viewport, solicita fullscreen
onde permitido e oferece o botão de ativação. Use F11 no desktop se necessário.

PUBLICAÇÃO NO GITHUB PAGES:
1) Extraia o ZIP e envie os quatro arquivos diretamente à raiz do repositório.
2) Settings > Pages > Build and deployment > Deploy from a branch.
3) Escolha main e /(root) e clique em Save.
4) Abra o link do GitHub Pages.
