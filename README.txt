ROLETA ILHA10 — SORTEIO DE TRIOS (SOL, ESTRELA, LUA)
====================================================

PUBLICAÇÃO NO GITHUB PAGES

  index.html
  style.css
  script.js
  ILHA10.png   (seu arquivo de imagem, já na raiz do GitHub)

A imagem ILHA10.png não foi incluída no ZIP: será carregada pelo CSS.
O título "Compartilhar experiências, ampliar possibilidades." é HTML,
em duas linhas centralizadas no topo da página.

COMO FUNCIONA O SORTEIO
Cada clique em GIRAR ROLETA seleciona UM participante.
O sistema cria uma sequência aleatória com exatamente um ícone de cada tipo:
SOL, ESTRELA e LUA. A ordem muda aleatoriamente a cada trio.
Dentro de cada tipo, sorteia aleatoriamente um participante disponível.
Assim, depois de TRÊS giros, sai um trio com símbolos distintos.
O giro seguinte inicia outro trio, com nova sequência aleatória.

Com a opção "Não repetir nomes" ativada (padrão), há 4 participantes
com SOL, 3 com ESTRELA e 3 com LUA. Portanto serão 3 trios completos
(9 participantes) e 1 giro final individual de SOL, para contemplar
os 10 participantes sem repetir ninguém.

Com "Não repetir nomes" desativado, todos os trios possuem 3 giros,
mas um nome pode reaparecer em outra rodada.
