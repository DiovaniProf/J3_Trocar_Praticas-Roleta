ROLETA DA ILHA — GITHUB PAGES
============================

ARQUIVOS (todos na RAIZ do repositório)
- index.html
- style.css
- script.js
- ILHA.jpg

COMO PUBLICAR
1. Extraia o ZIP.
2. Envie os quatro arquivos acima para a raiz do repositório no GitHub.
3. No GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecione a branch principal (main), pasta /(root), e salve.
5. Abra o endereço do GitHub Pages indicado pelo GitHub.

RECURSOS
- 10 nomes predefinidos (Daniela não está na lista).
- Botão GIRAR ROLETA e indicador fixo.
- Sorteio aleatório sem repetição, ativado por padrão.
- Alternativa para permitir repetição.
- Histórico, contador, resultado em destaque e botão Reiniciar.
- Estado preservado no navegador, quando o armazenamento local é permitido.
- Funciona também offline, abrindo o index.html.
- Responsividade, teclado, redução de movimento, sem dependências externas.

EDITAR NOMES
Abra script.js e altere apenas a lista const NOMES, no começo do arquivo.
Mantenha os nomes entre aspas e separados por vírgulas.
Após alterar a lista, clique em Reiniciar para apagar o histórico anterior.

IMPORTANTE
O texto do título já está incorporado ao arquivo ILHA.jpg, portanto não
foi duplicado no HTML visível. O arquivo deve ter exatamente o nome ILHA.jpg
(letras maiúsculas e extensão .jpg), pois GitHub Pages diferencia maiúsculas.
JavaScript é o nome da linguagem do arquivo script.js, não Java.
