O QUE MUDOU
- Todos os nomes são desenhados radialmente, começando na circunferência e
  seguindo para o centro, SEM inverter a direção na metade esquerda.
- Um ícone vetorial aparece ao final de cada nome:
  ESTRELA: KELI, CRISTIANE, DIJALMARY
  LUA: TIAGO, ROSEMERI, ANDREIA
  SOL: EDENILSE, ILSE, LILIANA, MARIANE
- No resultado e no histórico, o mesmo símbolo acompanha o participante.
- Mantidos dez participantes (sem Daniela), roleta animada, histórico,
  exclusão de repetidos, reiniciar, opções e imagem noturna ILHA2.jpg.

TELA CHEIA
O painel ocupa imediatamente toda a área da página (100dvh).
O script solicita Fullscreen API na abertura e também tenta ativá-la no
primeiro clique/toque/tecla; há ainda um botão de tela cheia no canto.
ATENÇÃO: Chrome, Firefox, Edge e Safari normalmente bloqueiam fullscreen real
na abertura de um site sem ação explícita do usuário. Nenhum código HTML/CSS/JS
publicado no GitHub Pages consegue ignorar essa regra do navegador.
Para apresentação sem barras, use o botão de tela cheia ou F11.

PUBLICAR NO GITHUB PAGES
1. Extraia o ZIP.
2. Envie os arquivos acima diretamente à raiz do repositório.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Abra o endereço publicado e atualize a página com Ctrl+F5, se for preciso.

Não é necessário instalar nada nem usar bibliotecas externas.
